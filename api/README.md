# キャリアコンサルタント過去問アプリ

## 概要

キャリアコンサルタント試験の過去問を効率的に学習するためのWebアプリです。
「1問ずつ解く」「間違えた問題を復習する」という学習体験に特化して設計しました。

---

## 背景・目的

資格試験の学習において、以下の課題を感じたため開発しました。

* 問題集だと復習がしづらい
* 間違えた問題だけを効率的に解き直したい
* 学習履歴を残したい

👉 これらを解決するため、
**「不正解問題を自動で蓄積する仕組み」**を中心に設計しました。

---

## 機能一覧

### 問題機能

* 問題詳細表示
* 選択式回答
* 正誤判定
* 自分の回答表示
* 正解表示（不正解時）

### ナビゲーション

* 前の問題へ
* 次の問題へ

### 学習管理

* 回答履歴の保存
* 不正解問題の記録
* 正解時に復習対象から除外

## 設計

### データ設計のポイント

#### ① 回答履歴をすべて保存

```ts
UserQuestionAnswer
```

* すべての回答を蓄積
* 学習履歴として活用可能

---

#### ② 不正解問題を別管理

```ts
WrongQuestion
```

* 不正解のみ保存
* 復習対象を明確化

---

#### ③ 正解時に復習から除外

```ts
resolvedAt を更新
```

👉 「できるようになった問題」を管理

---

### 設計意図

* 学習効率を最大化するための構造
* フロントはシンプルに（1問ずつ）
* DBで学習状態を管理
